Grading

Two grades per program

Stage is the furthest point of active development, for example a Phase 3 trial that is enrolling. Evidence is the highest-quality human data that has actually been read out. Evidence can never be ahead of stage. A program at Phase 3 stage with Phase 1 evidence has a lot left to prove.

Combined-phase trials (for example Phase 1/2) are graded at the lower phase. Registry phases feed a check, not the grade: if the registry shows an active trial ahead of the curated stage, the program gets a flag for review.

Verification

When a flag is raised

  • A tracked trial is terminated, withdrawn or suspended while the program is marked active.
  • A registry primary completion date has passed but the trial still says recruiting.
  • An active trial's registry record hasn't been updated in 18 months.
  • The registry lists an active trial at a later phase than the curated stage.
  • A curated record hasn't been re-verified in {{ 120 }} days.
  • A source link returns 404 or 410 in the weekly link check.
  • Anything the curator could not confirm from a primary source is listed as Unverified.

Flags are shown on each program page with an icon and a label: ! alert, ▲ warning, i note.

Rules

What the data never does

  • Guess. Unknown values are shown as unknown or "not disclosed".
  • Add precision. A date guided to "later this year" is shown as guidance, not a day.
  • Treat a registry primary completion date as a results date.
  • Reproduce article text. Headlines appear as links only.
  • Mix opinion with data. Personal notes are labelled "My take"; interpretation is labelled "Analysis".

How it's built

Pipeline

  1. A GitHub Action runs every morning.
  2. Python pulls ClinicalTrials.gov, PubMed, openFDA, SEC EDGAR and market data, merges them with the curated YAML records, and writes JSON.
  3. The same job runs the Cure Impact Model and renders every page as static HTML, plus the calendar file, CSV and sitemap.
  4. GitHub Pages serves the result. No server, no database, no tracking.
Caveats

Known limitations

  • yfinance is an unofficial wrapper around Yahoo Finance. Prices can be delayed and it can break.
  • Registry fields are entered by sponsors and are often out of date; that is what the flags are for.
  • Market-size estimates vary widely between research firms; the model shows the published range.
  • Curated records are maintained by one person.
